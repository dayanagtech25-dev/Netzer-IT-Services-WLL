Fiber Optic Installation FAQ

When should I use fiber instead of copper?

Use fiber when the run is longer than about 90 metres, when it joins two buildings, or when you need a fast link between switches.

Can you connect two buildings with fiber?

Yes. We plan the route, install outdoor rated cable and test the link end to end.

Do you test the fiber after installation?

Yes. We measure the loss on every link and give you the results in writing.
