Network Testing & Certification FAQ

What is cable certification?

It is a set of tests run with a certifier tool. The result shows if a cable meets the standard for the speed you need.

Do I need to test cabling that is already installed?

It is worth it if the network is slow, drops often, or you plan to upgrade to faster switches.

What do I get after the test?

You get a report listing each cable with a pass or fail result, and our advice on any that need fixing.
